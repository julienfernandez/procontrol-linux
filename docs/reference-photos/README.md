# Photos de référence consultées le 13 septembre 2026

Copies locales de travail demandées pour lire les commandes de la console.
Ces photos tierces ne sont pas couvertes par la licence GPL du code du projet.
Les images de travail restent locales et sont exclues du dépôt Git ; les liens
ci-dessous conservent leur provenance.

- Vue complète : [annonce eBay source](https://www.ebay.com/itm/235225035006).
- CHANNEL MATRIX / clavier / transport :
  [article Sound On Sound, mai 1999](https://www.soundonsound.com/reviews/digidesign-procontrol).

La photo de détail montre A–X sur les trois premières rangées, puis
Y, Z, SHIFT, CAPLCK, #, &, DELETE et SPACE. La vue complète montre également
les huit tranches, la section DSP, le compteur et les six grands vumètres.
Les inscriptions visibles ne donnent pas les adresses Ethernet : ces dernières
proviennent des sources de protocole et des captures.
